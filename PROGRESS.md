## Ограничения проверок и MVP
- Основной CUA browser/native host недоступен; вместо него выполнен headless Edge. Реальное переключение нативных вкладок не проверялось: visibilitychange моделировался в браузере.
- Физическое сканирование QR камерой не выполнялось; проверены PNG, канонический URL и загрузка изображения в браузере.
- Проверено на Windows/Python 3.14.0; Linux/macOS и другие браузеры не запускались.
- Нет production rate limit, аккаунтов и реальных платежей — это за рамками MVP. Необязательный countdown не добавлен.
- Для QR на другом устройстве нужен PUBLIC_BASE_URL с доступным адресом сервера.
- При запрете browser storage данные живут только в текущей странице; README и интерфейс это объясняют.
- Невыполненных обязательных требований спецификации не выявлено. Git отсутствует, поэтому логические коммиты не создавались; push/публикация не выполнялись.
